Mayflower, the unlearnability audit
===================================

The engine can carry an opponent prior. Whether that helps against a real
opponent depends on learning the prior from games already played, and this
is what that costs. Evaluation is exact: every board is enumerated and
weighted by how often the opponent produces it, so the only sampling is in
the learning.

2. The same prior, learned without assuming its shape
----------------------------------------------------

  Fitting placement frequencies instead, theta 2.0, 64 slots to estimate
     games N          shots  of oracle   slots seen
          25         8.8420        51%          27
         100         8.7081        73%          37
         400         8.5812        94%          40
        1600         8.5440       100%          40
        6400         8.5273       102%          40

    A reading above 100% is not an error. The oracle here is the policy
    that believes the TRUE prior, which is not the optimal policy: the shot
    rule is greedy, so a belief slightly off the truth can score marginally
    better. The column measures progress toward a reference, not toward a
    ceiling.

    Of 64 slots the opponent ever uses only about the number in the last
    column. The rest are unidentifiable from any number of games, which is
    harmless: a placement the opponent never makes cannot be exploited.
